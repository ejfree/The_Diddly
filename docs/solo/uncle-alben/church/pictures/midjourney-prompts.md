# First Church — Midjourney Prompts

> Five prompts for the [First Church](../firstchurch.md) in Goka's red light district, written to match each other and the floor plans in this folder: the exterior front, the bar seen from the door, Alben's room, the kitchen, and the distillery. Each prompt repeats the same style, cast, and building wording, because Midjourney has no variables. If you change one anchor below, change it in every prompt.

## Notes

> **GM Note — the pit.** [firstchurch.md](../firstchurch.md#the-pit) now says the pit is raised 6 inches, with ramps in a 6-8-10 right triangle. At that height the platform is barely visible in an image, so the prompt says "raised only a few inches with shallow ramps." Midjourney can't draw exact dimensions.
>
> **GM Note — the ramp.** The ramps are a 6-8-10 right triangle in inches: a 6-inch rise, an 8-inch base, and a 10-inch ramp. They're steep on purpose. At that size they won't show in an image, so the prompt just says low and shallow.
>
> **GM Note — Solomon's road.** It starts in the open area behind the bar, beside the palanquin's spot at the west end of the counter. It then runs through the kitchen and up above the windows into Alben's room and the distillery. [firstchurch.md](../firstchurch.md#solomons-road) now says so. The prompts for the room and the distillery don't show the road's opening, so add "a narrow ten-inch gap high in the wall above the window" to either one if you want it visible.
>
> **GM Note — the force shield.** The force shield is **coming**, so the bar-view prompt shows it as if Alben already owns it, hanging on the front of the bar. Alben isn't wearing it, and it is not on the wall in his room. [inventory.md](../../inventory.md) and [character.md](../../character.md) don't list it yet and will pick it up from the next Foundry export.
>
> **GM Note — text in images.** Midjourney is poor at lettering. The **A2 / B2** marks on the outside of the doors and the **C** on the inside will come out as vague marks or wrong characters. The prompts only ask for "a small painted mark." Add the real letters afterward in an editor. The **C²** on the cups has the same problem, so the prompts spell it "C-squared."
>
> **GM Note — Alben's likeness.** Only the two prompts with Alben use `--cref`, with the same portrait URL as the existing tokens in [background.md](../../background.md#portraits). Confirm the URL is current.
>
> **GM Note — the cats.** They are in every prompt, but Midjourney will often drop translucent subjects. If they vanish, say so and I'll strengthen the wording. If it adds too many, change "a few" to "one."
